How it works

Three steps.
Zero grunt work.

Deck to signed memo in a fraction of what a junior associate spends on a first pass.

Step 01
📎

Submit the deal

Upload a PDF pitch deck or describe the company in plain English. The intake agent extracts company, stage, thesis, founders, and financials — then asks only for what's missing.

Step 02
⚡

Swarm analyzes

Five AI agents run in parallel. Researcher, analyst, risk, writer, and critic each own specific chapters. An orchestrator sequences, gates on quality, and retries on failure.

Step 03
📄

Read the memo

A 14-chapter scrollytelling investment memo across five acts: Why → What → Who → How → So-what. Every claim traced to source. Verdict with score. IC-ready.

The swarm

Five agents.
One orchestrator.

Each agent is a specialist. No generalist slop. The critic catches hallucinations before you read a word.

Agent 01
📥
Ingest
Parses the pitch deck. Extracts all structured fields. Feeds every downstream agent with source-of-truth data.
Agent 02
🔍
Researcher
Independent market research. TAM, SAM, competition, macro context, geopolitics — all cited.
Agent 03
📊
Analyst
Unit economics, burn rate, ARR, LTV/CAC, payback period. Formulas locked to data room inputs.
Agent 04
⚠️
Risk
Cross-checks deck claims against research. Flags discrepancies. Red-teams the thesis. Surfaced inline.
Agent 05
✍️
Writer + Critic
Drafts all 14 chapters. Critic QA-gates every claim against a rubric before anything reaches you.
